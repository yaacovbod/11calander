# מצגת: דמוקרטיה ותקשורת

## מטרה
מצגת לימודית לתלמידי י"ב בנושא דמוקרטיה ותקשורת — חומר בגרות באזרחות. כוללת שבעה פרקים, מקרים אמיתיים מהעבר כממחישים, ומשימות לדיון.

## טכנולוגיה
HTML סטטי — קובץ `index.html` בודד עם CSS ו-JS מוטמעים. ללא build process.

## מבנה קבצים
```
democracy-media/
├── index.html    ← המצגת המלאה (כל הקוד)
├── CLAUDE.md     ← קובץ זה
└── files/        ← קבצים להגשה (PDF וכד')
```

## פרקי המצגת
1. מהי דמוקרטיה
2. תקשורת ודמוקרטיה
3. שלוש מטאפורות לתפקוד התקשורת
4. חופש הביטוי ומגבלותיו
5. לשון הרע והוצאת דיבה
6. זכות הציבור לדעת ופגיעה בפרטיות
7. מידע מהליכים פליליים

## מקרים אמיתיים משולבים
- בג"ץ "קול העם" 1953 — מבחן הוודאות הקרובה (השופט אגרנט)
- פרשת הרב כהנא ורשות השידור 1984 — גבולות חופש הביטוי
- "חוק בשורת איוב" — רונה רמון ואסף רמון — זכות הפרטיות
